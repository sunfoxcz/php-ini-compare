PHP INI differences on Ubuntu LTS

Ubuntu packages compared with Ondřej Surý’s packages of the same PHP major and minor version. Each PHP-FPM snapshot comes from a real FastCGI request to the package’s default pool.

How to read the report

Each pair uses an isolated, fresh amd64 install with the same requested PHP extensions. The PHP patch and packaging revisions may differ. Global and local values are the effective values reported by PHP. Quoted strings are shown verbatim; an empty string, null and an unregistered directive have separate meanings. Access is PHP’s INI access bitmask. FPM pool directives such as pm.max_children fall outside PHP INI settings.
